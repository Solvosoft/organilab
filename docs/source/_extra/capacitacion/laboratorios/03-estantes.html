3. Estantes

Los estantes son las unidades de almacenamiento dentro de los muebles. Cada estante ocupa una posición en la cuadrícula del mueble y puede configurarse con diferentes tipos, capacidades y restricciones para controlar qué objetos se almacenan en él.

Tipos de Contenedor

Cada estante tiene un tipo de contenedor que describe su forma física. Este tipo se selecciona de un catálogo configurable. Los tipos más comunes son:

Tipo Descripción Ejemplo de Uso
Compartimento Espacio abierto en una repisa o estantería Repisa de un gabinete donde se colocan frascos de reactivos
Cajón Espacio cerrado deslizable dentro del mueble Cajón de una cajonera para guardar materiales pequeños
Catálogo personalizable Los tipos de contenedor se gestionan desde el catálogo del sistema. Los administradores pueden agregar nuevos tipos si los predefinidos no cubren las necesidades de su laboratorio.

Propiedades del Estante

Cada estante tiene varias propiedades que controlan su comportamiento y capacidad. A continuación se describen las más importantes:

Propiedad Descripción Valor por Defecto
Nombre Nombre descriptivo del estante (obligatorio)
Tipo de contenedor Forma física del estante (compartimento, cajón, etc.) (obligatorio)
Cantidad (capacidad) Capacidad máxima del estante expresada en la unidad de medida seleccionada 0
Unidad de medida Unidad en que se mide la capacidad (litros, kilogramos, unidades, etc.) (obligatorio)
Descarte Indica si el estante es un contenedor de descarte para residuos No
Cantidad infinita Permite que el estante no tenga límite de capacidad No
Limitar objetos Restringe los objetos que pueden almacenarse a una lista predefinida No
Color Color visual para identificar el estante en la cuadrícula del mueble Gris
Estante contenedor Permite anidar este estante dentro de otro estante (ninguno)

Capacidad y Unidades de Medida

La capacidad de un estante se define mediante dos valores: la cantidad y la unidad de medida. Juntos, determinan cuánto material puede almacenarse en el estante.

Ejemplo: Estante de Líquidos

Capacidad: 20 litros

Este estante puede almacenar reactivos líquidos cuya suma total no supere los 20 litros. Si se intenta agregar un reactivo que exceda esta capacidad, el sistema mostrará una advertencia.

Ejemplo: Estante de Materiales

Capacidad: 50 unidades

Este estante puede contener hasta 50 unidades de materiales de laboratorio (probetas, pipetas, matraces, etc.). El sistema controla que no se exceda este límite.

Estantes de Descarte

Un estante de descarte es un espacio designado específicamente para depositar residuos o materiales que deben ser eliminados. Cuando un estante tiene activada la opción discard=True, cumple las siguientes funciones:

  • Recibe objetos que han sido marcados para descarte desde otros estantes
  • Permite llevar un registro de los residuos generados en el laboratorio
  • Facilita el control de la disposición final de reactivos vencidos o contaminados
  • Se diferencia visualmente de los estantes regulares en la cuadrícula del mueble
Buena práctica Es recomendable crear al menos un estante de descarte por laboratorio para poder registrar adecuadamente los residuos. Esto facilita el cumplimiento de las normativas ambientales y de seguridad vigentes.

Limitar Objetos en un Estante

La opción limitar objetos (limit_only_objects) permite restringir qué tipos de objetos pueden almacenarse en un estante específico. Cuando esta opción está activada, solo los objetos incluidos en la lista de objetos permitidos (available_objects_when_limit) pueden ser agregados al estante.

Esta funcionalidad es útil en situaciones como:

  • Estantes exclusivos para ácidos — Solo se permite almacenar ácidos concentrados, evitando mezclas peligrosas con bases o solventes.
  • Estantes de equipos específicos — Solo se permite almacenar ciertos instrumentos de medición calibrados.
  • Estantes de materiales controlados — Solo se permite almacenar sustancias precursoras que requieren trazabilidad especial.

Cantidad Infinita

En algunos casos, no es práctico definir un límite de capacidad para un estante. La opción cantidad infinita permite desactivar el control de capacidad, permitiendo agregar objetos sin restricción de cantidad.

¿Cuándo usar cantidad infinita? Esta opción es útil para estantes de almacenamiento general donde el control de capacidad no es crítico, como mesas de trabajo donde se colocan equipos temporalmente, o estantes de tránsito donde los objetos están de paso.

Estantes Anidados (Contenedores)

Organilab permite crear una relación de contención entre estantes a través de la propiedad estante contenedor (container_shelf). Esto significa que un estante puede estar "dentro" de otro estante, creando una jerarquía de almacenamiento más detallada.

Ejemplos de uso:

  • Una caja dentro de un compartimento de un gabinete
  • Un recipiente secundario dentro de un compartimento de seguridad
  • Un organizador dentro de un cajón

Codificación por Colores

Cada estante puede tener un color asignado que se muestra en la representación visual de la cuadrícula del mueble. Esta codificación por colores facilita la identificación visual rápida de los estantes y su contenido.

Algunos usos comunes de la codificación por colores:

  • Rojo — Estantes con sustancias peligrosas o inflamables
  • Azul — Estantes con reactivos que requieren refrigeración
  • Verde — Estantes con materiales de uso general
  • Amarillo — Estantes de descarte o residuos
  • Naranja — Estantes con sustancias precursoras
