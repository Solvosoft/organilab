4. Carga Masiva de Inventario de Reactivos

La carga masiva permite importar múltiples reactivos al inventario del laboratorio de forma simultánea mediante un archivo. Este proceso facilita la actualización rápida del inventario sin necesidad de ingresar cada elemento individualmente.

Solo roles autorizados La carga masiva de inventario requiere permisos de nivel administrador. Esta operación puede agregar grandes cantidades de datos al sistema, por lo que debe realizarse con cuidado y con un archivo correctamente preparado.

Información solicitada para la carga

Al realizar una carga masiva, el sistema solicita los siguientes datos:

Campo Descripción Requerido
Archivo de inventario Archivo con el listado de reactivos a importar (formato indicado por el sistema) Sí
Lugar conocido Indica si la ubicación de los reactivos ya existe en el sistema Sí
Sala de laboratorio Sala destino donde se ubicarán los reactivos importados Sí
Mueble Mueble específico dentro de la sala Sí
Estante Estante dentro del mueble donde se almacenarán Sí

Procedimiento de carga masiva

  1. Preparar el archivo de inventario — Debe seguir el formato requerido por el sistema. Consulte la plantilla de ejemplo disponible en el módulo.
  2. Ingresar a la subárea "Carga de inventario de reactivos" — Dentro de Administración del Laboratorio.
  3. Seleccionar si la ubicación es un lugar conocido — Si los reactivos ya tienen una ubicación registrada en el sistema, marque esta opción.
  4. Especificar la ubicación destino — Seleccione la sala, el mueble y el estante donde se almacenarán los reactivos importados.
  5. Cargar el archivo — Use el botón de carga para seleccionar el archivo desde su computadora.
  6. Confirmar la importación — Revise el resumen antes de confirmar y ejecutar la carga.
  7. Verificar los resultados — El sistema mostrará un resumen de los registros importados exitosamente y los que presentaron errores.

Permisos y restricciones

La modificación, creación o eliminación de registros mediante carga masiva depende de los permisos asignados al perfil del usuario. Solo los roles autorizados podrán:

  • Crear registros nuevos
  • Editar registros existentes
  • Eliminar registros
  • Cargar inventario masivamente
  • Modificar condiciones de proceso
Precaución Verifique siempre el archivo antes de cargarlo. Una carga masiva con datos incorrectos puede introducir errores en el inventario que después son difíciles de corregir. Realice una prueba con un archivo pequeño antes de cargar el inventario completo.
