3. Roles y Tipos de Usuario

Organilab distingue entre tipos de usuario (la categoría general del usuario dentro de la organización) y roles (conjuntos específicos de permisos personalizables).

Tipos de Usuario en la Organización

Cuando un usuario se vincula a una organización, se le asigna uno de tres tipos que definen su nivel general de acceso:

Administrador

Tiene gestión completa de la organización. Puede:

  • Crear y eliminar organizaciones hijas
  • Crear laboratorios (si es org raíz)
  • Registrar y gestionar usuarios
  • Crear, modificar y eliminar roles
  • Asignar roles a otros usuarios
  • Configurar todas las opciones del sistema
Acceso total

Gestor de Laboratorio

Administra laboratorios específicos dentro de la organización. Puede:

  • Gestionar el inventario del laboratorio
  • Administrar sustancias, equipos y materiales
  • Gestionar las salas y muebles
  • Generar reportes del laboratorio
  • Gestionar reservaciones
Acceso a laboratorios

Usuario de Laboratorio

Tiene acceso operativo al laboratorio. Puede:

  • Consultar el inventario
  • Ver sustancias y sus fichas de seguridad
  • Realizar reservaciones
  • Consultar procedimientos
  • Acceso limitado según los roles asignados
Acceso básico
Tipo vs. Rol El tipo de usuario define la categoría general (administrador, gestor, usuario). Los roles definen permisos específicos y detallados. Un usuario de tipo "Gestor de Laboratorio" puede tener diferentes roles en diferentes laboratorios.

¿Qué es un Rol?

Un rol es un conjunto de permisos agrupados bajo un nombre descriptivo. Los roles permiten asignar múltiples permisos a un usuario de una sola vez, en lugar de asignarlos uno por uno.

Características de un Rol

Característica Descripción
Nombre Identificador descriptivo del rol (ej: "Regente Químico", "Técnico de Lab")
Color Color identificador visual para facilitar la distinción entre roles en la interfaz
Permisos Lista de acciones específicas que el rol permite realizar
Descripción Texto explicativo sobre el propósito del rol (opcional)

Roles Típicos en una Universidad

A continuación se presentan ejemplos de roles comunes que una universidad podría definir en Organilab:

Rol Descripción Permisos Típicos
Regente Químico Responsable de la seguridad química en los laboratorios de una sede o facultad Ver y gestionar sustancias, SGA, hojas de seguridad, etiquetas, zonas de riesgo, reportes
Administrador de Laboratorio Responsable de la operación completa de un laboratorio Gestión completa del inventario, usuarios del lab, reservaciones, reportes, procedimientos
Técnico de Laboratorio Personal técnico que opera el laboratorio diariamente Inventario, movimientos de sustancias, gestión de muebles, reservaciones
Docente Profesor que utiliza el laboratorio para clases Consultar inventario, realizar reservaciones, ver procedimientos
Estudiante Estudiante que accede al laboratorio para prácticas Consultar inventario (solo lectura), ver sustancias y sus fichas
Auditor Persona que revisa el cumplimiento de normas Ver reportes, informes, procedimientos, sustancias (solo lectura)
Personalización total Estos son solo ejemplos. Usted puede crear los roles que necesite su institución, con exactamente los permisos que cada función requiere. No hay límite en la cantidad de roles que puede definir.

Crear un Rol Nuevo

Para crear un nuevo rol, acceda a la administración de la organización y seleccione la opción de agregar rol. Puede crear un rol vacío (sin permisos) e ir agregando permisos conforme navegue por el sistema, o copiar los permisos de un rol existente.

Opción 1: Rol nuevo sin copiar permisos

Cree el rol con un nombre descriptivo. Los permisos se agregarán después, conforme se necesiten.

Formulario para crear un rol nuevo sin copiar permisos de otros roles

Opción 2: Rol nuevo copiando permisos de otro rol

Si ya existe un rol similar, puede crear el nuevo rol copiando los permisos del existente y luego ajustarlos según sea necesario.

Formulario para crear un rol nuevo copiando permisos de roles existentes

Copiar un rol a otra organización

Si necesita el mismo rol en varias organizaciones (por ejemplo, el rol "Técnico" en cada sede), puede copiar un rol existente a otra organización. Se copian:

  • El nombre del rol
  • El color identificador
  • Todos los permisos asociados

Eliminar un rol

Precaución Al eliminar un rol, se remueven todas sus relaciones con usuarios y organizaciones. Los usuarios que tenían ese rol perderán los permisos asociados. Esta acción es definitiva y no se puede deshacer.
