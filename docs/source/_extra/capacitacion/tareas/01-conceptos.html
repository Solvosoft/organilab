1. Conceptos de Tareas Programadas

Las tareas programadas son procesos automáticos que Organilab ejecuta en horarios predefinidos para realizar operaciones de mantenimiento, generar reportes y enviar notificaciones. Estas tareas funcionan sin intervención del usuario y son fundamentales para mantener el sistema actualizado.

¿Qué son las Tareas Programadas?

En Organilab, muchas operaciones necesitan ejecutarse de forma periódica: verificar si algún reactivo está por debajo de su nivel mínimo, enviar correos de alerta sobre productos próximos a vencer, o generar reportes mensuales de precursores químicos. Estas operaciones no pueden depender de que un usuario las ejecute manualmente, ya que podrían olvidarse o retrasarse.

Para resolver esto, Organilab utiliza un sistema de tareas en segundo plano. Este sistema funciona como un programador de actividades que se encarga de ejecutar cada tarea en el momento exacto configurado, de forma autónoma y confiable.

Cómo Funciona el Sistema

El sistema de tareas programadas de Organilab se compone de tres elementos principales:

Programador de tareas (Celery Beat)
Es el reloj del sistema. Se encarga de revisar continuamente el horario configurado y, cuando llega el momento, envía la orden de ejecutar la tarea correspondiente. Funciona como un despertador que se activa a las horas programadas.
Cola de mensajes (RabbitMQ)
Es el canal de comunicación entre el programador y los ejecutores. Cuando el programador determina que es hora de ejecutar una tarea, coloca un mensaje en la cola. Esto garantiza que la tarea se procese incluso si el ejecutor está ocupado con otra operación en ese momento.
Ejecutor de tareas (Celery Worker)
Es el proceso que realiza el trabajo real. Toma los mensajes de la cola y ejecuta las operaciones correspondientes: enviar correos, generar reportes, verificar inventarios, etc.

Diagrama: El programador envía órdenes a la cola de mensajes, el ejecutor las procesa y produce resultados como emails, reportes o tareas de limpieza.

Zona Horaria

Todas las tareas programadas en Organilab se ejecutan en la zona horaria America/Costa_Rica (UTC-6). Esto significa que cuando una tarea está configurada para las 07:00, se ejecutará a las 7 de la mañana hora de Costa Rica, independientemente de dónde se encuentre el servidor.

Zona horaria consistente La configuración de zona horaria garantiza que las alertas de expiración, los reportes y las notificaciones se generen en horarios coherentes con la jornada laboral de los usuarios en Costa Rica.

Tabla Completa de Tareas

A continuación se presenta la lista completa de tareas programadas en Organilab, incluyendo su horario de ejecución y una breve descripción de lo que hace cada una:

Tarea Horario Descripción
Envío de correos acumulados Diaria 00:02 Envía las notificaciones por correo electrónico que se acumularon durante el día
Alerta de límite de inventario Diaria 06:50 Verifica si algún reactivo está por debajo de su cantidad mínima y envía alerta
Alerta de expiración Diaria 07:00 Notifica sobre reactivos que expiran al día siguiente
Registro de stock máximo Diaria 10:00 Registra el inventario máximo diario de cada reactivo por laboratorio
Reportes de establecimientos Diaria 16:45 Genera reportes de gestión de riesgo de los establecimientos
Reportes de precursores Mensual (día 1) 00:02 Genera el reporte mensual de precursores químicos para todos los laboratorios
Limpieza de estantes huérfanos Periódica Elimina estantes que ya no están referenciados en ningún mueble
Informes periódicos Según configuración Genera informes automáticos basados en la configuración del InformScheduler
Decremento de stock Bajo demanda Reduce la cantidad en inventario cuando se inicia una reservación aprobada
Tareas bajo demanda Algunas tareas no tienen un horario fijo. La tarea de decremento de stock, por ejemplo, se ejecuta automáticamente cuando llega la fecha de inicio de una reservación aprobada. La limpieza de estantes huérfanos se ejecuta periódicamente según la configuración del sistema.
