4. Mantenimiento del Sistema

Organilab ejecuta tareas de mantenimiento automáticas que garantizan la integridad de los datos, eliminan registros obsoletos y mantienen el rendimiento óptimo del sistema. Estas tareas son invisibles para el usuario final pero son esenciales para el correcto funcionamiento de la plataforma.

Limpieza de Estantes Huérfanos

La tarea de limpieza de estantes huérfanos (remove_shelf_not_furniture) se encarga de identificar y eliminar estantes que ya no están asociados a ningún mueble en el sistema. Un estante se considera "huérfano" cuando no aparece referenciado en la configuración de datos (dataconfig) de ningún mueble.

Por qué se Generan Estantes Huérfanos

Los estantes huérfanos pueden aparecer en situaciones como las siguientes:

  • Reconfiguración de muebles — Cuando un administrador modifica la cuadrícula de un mueble (por ejemplo, reduce de 4 filas a 3), los estantes que estaban en la fila eliminada pueden quedar sin referencia en el mueble.
  • Eliminación de muebles — Si se elimina un mueble del sistema, los estantes asociados podrían no eliminarse correctamente en todos los casos.
  • Migraciones de datos — Durante actualizaciones del sistema o migraciones de base de datos, pueden generarse inconsistencias temporales.

La tarea de limpieza revisa periódicamente todos los estantes del sistema y compara sus identificadores con los que aparecen en las configuraciones de los muebles. Los estantes que no coinciden con ninguna configuración son eliminados automáticamente.

Estantes con objetos Antes de eliminar un estante huérfano, el sistema verifica que no contenga objetos. Si un estante huérfano todavía tiene objetos registrados, la situación se reporta para que un administrador tome las medidas necesarias antes de proceder con la limpieza.

Limpieza de Sesiones Expiradas

Cuando los usuarios inician sesión en Organilab, el sistema crea un registro de sesión que mantiene al usuario autenticado. Estas sesiones tienen una duración limitada y, una vez expiradas, deben eliminarse de la base de datos para mantener el rendimiento del sistema.

La limpieza de sesiones expiradas realiza las siguientes acciones:

  • Identifica todas las sesiones cuya fecha de expiración ya ha pasado
  • Elimina los registros de sesión expirados de la base de datos
  • Libera espacio en la tabla de sesiones para mejorar el rendimiento de las consultas

En un sistema con muchos usuarios activos, la tabla de sesiones puede crecer significativamente si no se limpia regularmente. La eliminación periódica de sesiones expiradas evita que esta tabla se convierta en un cuello de botella para el rendimiento.

Limpieza de Archivos Temporales

Organilab genera archivos temporales durante diversas operaciones: exportación de reportes, generación de documentos PDF, procesamiento de imágenes y otras tareas que requieren almacenamiento intermedio. Estos archivos se acumulan con el tiempo y deben eliminarse periódicamente.

La tarea de limpieza de archivos temporales:

  • Busca archivos en los directorios temporales del sistema que superen cierta antigüedad
  • Verifica que no estén siendo utilizados por ninguna operación activa
  • Elimina los archivos que ya no son necesarios
  • Registra la cantidad de archivos eliminados y el espacio liberado

Importancia del Mantenimiento Automático

Las tareas de mantenimiento, aunque no producen resultados visibles para el usuario final, son fundamentales para la salud del sistema a largo plazo. Sin ellas, la base de datos acumularía registros innecesarios, el almacenamiento se llenaría de archivos temporales y el rendimiento del sistema se degradaría progresivamente.

Integridad de datos Las tareas de mantenimiento protegen la integridad de los datos del sistema. Los estantes huérfanos, por ejemplo, pueden causar inconsistencias en los reportes de inventario si no se eliminan a tiempo. Las sesiones expiradas acumuladas pueden ralentizar el proceso de autenticación. Y los archivos temporales sin limpiar pueden consumir todo el espacio disponible en el servidor. El mantenimiento automático previene estos problemas antes de que afecten a los usuarios.

Responsabilidades del Administrador

Aunque las tareas de mantenimiento son automáticas, el administrador del sistema debe:

  1. Verificar que las tareas se están ejecutando — Revisar periódicamente el panel de administración de tareas para confirmar que todas las tareas programadas se ejecutan según su horario.
  2. Monitorear los registros de ejecución — Revisar los registros (logs) del sistema para detectar errores o advertencias en la ejecución de las tareas de mantenimiento.
  3. Atender las alertas — Si una tarea de limpieza detecta una situación que requiere intervención manual (como un estante huérfano con objetos), el administrador debe resolver la situación.
  4. Mantener los servicios activos — Asegurarse de que los servicios de ejecución de tareas en segundo plano (Celery Worker y Celery Beat) estén siempre en funcionamiento. Si estos servicios se detienen, ninguna tarea programada se ejecutará.
Servicios detenidos Si el servicio de ejecución de tareas se detiene por cualquier razón (reinicio del servidor, error del sistema, etc.), todas las tareas programadas dejarán de ejecutarse. Esto significa que no se enviarán notificaciones, no se generarán reportes y no se realizará mantenimiento. Es responsabilidad del administrador verificar regularmente que estos servicios estén activos y configurar mecanismos de reinicio automático.
