Capítulo 12: Tutoriales y Documentación

El módulo Tutoriales y Documentación tiene como finalidad brindar apoyo al usuario mediante recursos de consulta rápida, guías funcionales, reglamentos y documentación oficial cargada en el sistema.

¿Cuándo usar este módulo? Se recomienda utilizar esta sección cuando el usuario necesite:
  • Aprender a utilizar una función del sistema
  • Ubicar una opción dentro del sistema
  • Validar el flujo correcto de un proceso
  • Conocer la finalidad de un módulo
  • Consultar reglamentos o normativas institucionales

Acceso al módulo

  1. Seleccionar la organización o laboratorio activo
  2. Ingresar al menú principal
  3. Seleccionar Tutoriales y Documentación

Qué ofrece el módulo

El módulo permite acceder a:

  • Tutoriales de uso por módulo del sistema
  • Guías rápidas de funciones específicas
  • Documentación de apoyo técnico
  • Reglamentos institucionales
  • Manuales internos del laboratorio
  • Documentos institucionales

Contenido del Capítulo

1. Módulo de Tutoriales

Cómo funciona el módulo de tutoriales interactivos, qué contenido incluye y cómo usarlos para aprender a usar las diferentes secciones del sistema.

2. Documentación y Reglamentos

Consulta de manuales de usuario, reglamentos institucionales, instructivos, normativas y documentos de respaldo cargados en el sistema.
