1. Módulo de Tutoriales

La opción Tutoriales dentro del módulo de Tutoriales y Documentación permite al usuario visualizar guías rápidas sobre el uso de los diferentes módulos del sistema Organilab.

¿Qué son los tutoriales del sistema?

Los tutoriales son guías interactivas o explicativas que muestran, de forma resumida y visual, cómo utilizar cada módulo del sistema. Están diseñados para facilitar el aprendizaje rápido de nuevos usuarios y como referencia para usuarios que necesitan refrescar alguna función.

Según el manual del sistema, cada tutorial muestra un pequeño detalle explicativo de:

  • Dónde se encuentra cada módulo dentro del sistema
  • Qué funciones posee el módulo
  • Qué acciones se pueden realizar

Contenido de los tutoriales

Los tutoriales pueden incluir explicaciones sobre módulos como:

Módulo Tipo de contenido
Mis Laboratorios Gestión de inventario, reactivos, materiales, equipos
Registro de Usuarios Registro con QR, gestión de accesos
Administración del Laboratorio Configuración técnica, proveedores, carga masiva
Reportes Generación de informes, tipos de reporte
Zonas de Riesgo Regentes, edificios, estructuras, zonas
MSDS Consulta y carga de hojas de seguridad
SGA Etiquetas, pictogramas, frases H y P
Desechos Clasificación y seguimiento de residuos
Organizaciones y Permisos Estructura organizacional, roles, usuarios

Cómo usar los tutoriales

El módulo de tutoriales facilita la navegación y la capacitación de nuevos usuarios. Para utilizarlos:

  1. Acceder al módulo Tutoriales y Documentación desde el menú principal.
  2. Seleccionar la opción Tutoriales.
  3. Elegir el módulo sobre el cual desea consultar.
  4. Seguir el tutorial paso a paso.
Recomendación para nuevos usuarios Se recomienda a los usuarios nuevos revisar los tutoriales antes de comenzar a usar el sistema. El orden sugerido es: Permisos → Laboratorios → Sustancias → Reportes.
