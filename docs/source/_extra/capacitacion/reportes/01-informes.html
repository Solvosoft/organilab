1. Informes Formales

Los informes formales son documentos estructurados con valor institucional y regulatorio, generados para regentes, autoridades administrativas y entes de control. Se pueden descargar en formatos como PDF, XLS y ODS.

Informe Regencial

Este informe es utilizado principalmente por el regente del laboratorio para reportar el estado del inventario ante las autoridades competentes.

Obligación regulatoria En muchas instituciones, el regente químico está obligado a presentar informes periódicos del inventario de sustancias. Este reporte facilita el cumplimiento de esa obligación.

Permite descargar información en formato:

  • XLS — Compatible con Microsoft Excel
  • ODS — Compatible con LibreOffice Calc (formato abierto)

Datos requeridos

CampoDescripción
ElementoSelección del elemento o tipo de sustancia a incluir en el informe
PeríodoRango de fechas para el cual se generará el informe

Procedimiento

  1. Seleccionar el elemento a reportar
  2. Indicar el período (fecha inicio y fecha fin)
  3. Presionar Enviar
  4. El sistema descarga automáticamente el archivo en el formato seleccionado

Informe de Inventario de Sustancias Químicas

Genera un inventario completo de las sustancias químicas registradas en el laboratorio. Incluye información detallada sobre cantidades, ubicaciones y características de cada sustancia.

Campo requerido: Laboratorio

Informe de Laboratorio por Compatibilidad

Genera un informe sobre la compatibilidad entre sustancias almacenadas en el laboratorio, basado en el Sistema Globalmente Armonizado (SGA). Permite identificar sustancias que no deben almacenarse juntas por incompatibilidad química.

Campo requerido: Laboratorio

Informe de Donaciones

Permite consultar y generar el registro de objetos o sustancias que han ingresado al laboratorio por medio de donaciones. Es útil para controles administrativos y auditorías de activos.

Campo requerido: Laboratorio
