3. Objetos Requeridos y Observaciones

Cada paso de un procedimiento puede tener objetos requeridos (reactivos, materiales y equipos) con cantidades específicas, así como observaciones de seguridad. Esta información es esencial para la planificación, la reservación automática y la ejecución segura.

Objetos requeridos por paso (ProcedureRequiredObject)

Un objeto requerido vincula un paso del procedimiento con un objeto del inventario del laboratorio. Para cada objeto requerido se especifica:

  • Objeto: El reactivo, material o equipo del inventario de Organilab que se necesita.
  • Cantidad: La cantidad numérica necesaria para ese paso.
  • Unidad de medida: La unidad en la que se expresa la cantidad (mL, g, unidades, etc.).

Agregar objetos a un paso

  1. Abra el procedimiento y seleccione el paso al que desea agregar objetos requeridos.
  2. En la sección de objetos requeridos del paso, haga clic en "Agregar Objeto".
  3. Seleccione el tipo de objeto: Reactivo, Material o Equipo.
  4. Busque y seleccione el objeto específico del inventario del laboratorio.
  5. Ingrese la cantidad requerida y seleccione la unidad de medida apropiada.
  6. Guarde y repita para cada objeto adicional que necesite el paso.

Formulario para agregar un objeto requerido a un paso del procedimiento

Ejemplo: Paso con objetos requeridos

A continuación se muestra un ejemplo de cómo se vería un paso completo con sus objetos requeridos para la preparación de una solución acuosa:

Paso 3: Preparar la solución ácida diluida
Medir 50 mL de ácido sulfúrico concentrado y agregarlo lentamente al matraz que contiene 450 mL de agua destilada. Agitar continuamente durante la adición.
Tipo Objeto Cantidad Unidad
Reactivo Ácido sulfúrico (H2SO4) 98% 50 mL
Reactivo Agua destilada 450 mL
Material Matraz Erlenmeyer 1000 mL 1 unidad
Material Probeta graduada 100 mL 1 unidad
Equipo Agitador magnético 1 unidad

Observaciones de seguridad (ProcedureObservations)

Además de los objetos requeridos, cada paso puede incluir observaciones de seguridad a través del modelo ProcedureObservations. Estas observaciones son advertencias críticas que el operador debe considerar antes y durante la ejecución del paso.

Importancia de las observaciones de seguridad Las observaciones de seguridad son fundamentales para prevenir accidentes. Siempre que un paso involucre sustancias peligrosas, equipos de alto riesgo o condiciones especiales, registre las advertencias correspondientes. Estas observaciones serán visibles para todos los operadores durante la ejecución del procedimiento.

Agregar observaciones a un paso

  1. Dentro del paso seleccionado, ubique la sección de Observaciones.
  2. Haga clic en "Agregar Observación".
  3. Escriba la descripción de la observación de seguridad. Sea claro y directo sobre el riesgo y las medidas de protección necesarias.
  4. Guarde la observación. Puede agregar múltiples observaciones por paso.

Siguiendo el ejemplo anterior del Paso 3, las observaciones de seguridad podrían ser:

Observación para Paso 3 PRECAUCIÓN: Siempre agregar el ácido al agua, nunca al revés. La reacción es altamente exotérmica. Usar campana de extracción, guantes de nitrilo, gafas de seguridad y bata de laboratorio. En caso de contacto con la piel, lavar inmediatamente con abundante agua.

Buenas prácticas para objetos y observaciones

  • Sea preciso con las cantidades: Indique cantidades exactas con las unidades correctas para evitar errores de dosificación.
  • Incluya todos los materiales: No olvide materiales auxiliares como pipetas, guantes o papel filtro que también son necesarios.
  • Registre observaciones para pasos críticos: Todo paso que involucre calor, sustancias corrosivas, tóxicas o inflamables debe tener observaciones de seguridad.
  • Referencie las hojas de seguridad: Cuando sea aplicable, mencione que el operador debe consultar la hoja de seguridad (MSDS) de las sustancias involucradas.
