4. Ejecutar Procedimiento

Una vez que la plantilla del procedimiento está lista, puede crear una instancia de ejecución (MyProcedure) para un laboratorio específico. La instancia permite registrar datos mediante formularios dinámicos, agregar comentarios colaborativos y gestionar el flujo de estados hasta la finalización.

Crear una instancia de ejecución

Una instancia de ejecución es una copia de trabajo de la plantilla del procedimiento, vinculada a una organización específica. Para crear una nueva instancia:

  1. Navegue al listado de procedimientos disponibles en su organización.
  2. Seleccione la plantilla del procedimiento que desea ejecutar.
  3. Haga clic en "Crear Instancia" o "Ejecutar Procedimiento".
  4. Asigne un nombre personalizado a la instancia. Por ejemplo: "Preparación NaOH 1M - Laboratorio Química - 15 marzo 2026".
  5. La instancia se creará en estado Borrador y estará lista para ser completada.

Flujo de estados de la instancia

La instancia de ejecución atraviesa tres estados. Solo los usuarios con los permisos adecuados pueden cambiar el estado de un procedimiento:

Borrador (Eraser) Estado inicial tras crear la instancia. En este estado el operador puede completar los formularios dinámicos de cada paso, registrar datos de ejecución, agregar comentarios y hacer modificaciones. El procedimiento permanece en borrador hasta que el operador considere que está listo para revisión.
En Revisión (In Review) El operador envía la instancia a revisión cuando ha completado todos los pasos. Un supervisor o responsable del laboratorio revisa los datos registrados, las observaciones y los comentarios. Puede aprobar el procedimiento para finalizarlo o rechazarlo para que se corrija.
Finalizado (Finalized) El procedimiento ha sido aprobado por el supervisor. En este estado los datos quedan como un registro histórico inmutable. No se permiten más modificaciones, pero la información permanece disponible para consulta, auditorías y reportes.

Formularios dinámicos (Formio.js)

Organilab utiliza Formio.js para generar formularios dinámicos asociados a cada instancia de ejecución. Estos formularios se definen mediante un esquema JSON almacenado en el campo schema de MyProcedure y permiten capturar datos estructurados durante la ejecución del procedimiento.

Los formularios dinámicos pueden incluir campos como:

  • Campos de texto: Para registrar observaciones y anotaciones.
  • Campos numéricos: Para registrar mediciones (peso, volumen, temperatura, pH).
  • Casillas de verificación: Para confirmar que un paso se completó correctamente.
  • Selectores de fecha y hora: Para registrar el momento exacto de cada acción.
  • Campos de carga de archivos: Para adjuntar fotografías o documentos de soporte.

Comentarios colaborativos por paso

El modelo CommentProcedureStep permite que múltiples usuarios agreguen comentarios a cada paso durante la ejecución. Esta funcionalidad es especialmente útil para:

  • Registrar incidencias o desviaciones observadas durante la ejecución.
  • Documentar decisiones tomadas en tiempo real.
  • Permitir que supervisores hagan retroalimentación sin modificar los datos originales.
  • Mantener un registro de comunicación entre el operador y el revisor.
  1. Navegue al paso del procedimiento donde desea agregar un comentario.
  2. En la sección de comentarios, escriba su observación o retroalimentación.
  3. Haga clic en "Agregar Comentario". El comentario quedará registrado con su nombre de usuario y la fecha y hora.

Sección de comentarios colaborativos en un paso del procedimiento en ejecución

Cambiar el estado del procedimiento

  1. Verifique que todos los pasos estén completos y que los formularios dinámicos tengan los datos requeridos.
  2. Desde la vista de la instancia, haga clic en "Enviar a Revisión" para cambiar el estado de Borrador a En Revisión.
  3. El supervisor revisa la instancia y puede hacer clic en "Aprobar" para finalizar el procedimiento o "Rechazar" para devolverlo a Borrador.
Nota sobre permisos El cambio de estado está controlado por el sistema de permisos de Organilab. Generalmente, los operadores pueden enviar a revisión, pero solo los supervisores o administradores pueden aprobar o rechazar un procedimiento. Consulte el Capítulo 1: Permisos para más detalles.
