4. Devolución de Productos

El proceso de devolución es la etapa final del ciclo de reservación. Aquí se registra la entrega de los productos prestados al laboratorio, se actualiza el inventario y se cierra la reservación cuando todos los productos han sido devueltos.

Devolución Parcial y Completa

El sistema permite registrar devoluciones de forma parcial o completa. Esto es útil cuando un usuario devuelve parte de los productos primero y el resto después:

  • Devolución completa: el usuario devuelve la totalidad de la cantidad prestada. El campo "cantidad devuelta" (amount_returned) se iguala a la "cantidad requerida" (amount_required) y el producto pasa al estado "Devuelto".
  • Devolución parcial: el usuario devuelve solo una parte de la cantidad prestada. El campo "cantidad devuelta" se actualiza con la cantidad parcial. El producto permanece en estado "Prestado" hasta que se complete la devolución.
Actualización automática del inventario Cada vez que se registra una devolución, el sistema incrementa automáticamente la cantidad del objeto en el estante correspondiente. Si se devuelven 5 unidades, el inventario del estante aumenta en 5 unidades. Esto garantiza que el inventario siempre refleje la disponibilidad real de los productos.

Proceso de Devolución

Para registrar la devolución de productos, siga estos pasos:

  1. Localizar la reservación: acceda al módulo de reservaciones y busque la reservación en estado "Aceptada" cuyos productos desea devolver. Puede filtrar por estado o buscar por usuario.
  2. Seleccionar los productos a devolver: dentro de la reservación, identifique los productos que están en estado "Prestado" y que el usuario desea devolver.
  3. Ingresar la cantidad devuelta: para cada producto, ingrese la cantidad que se está devolviendo. El sistema verifica que la cantidad devuelta no exceda la cantidad prestada.
  4. Confirmar la devolución: al confirmar, el sistema actualiza el campo "cantidad devuelta", incrementa el inventario del estante y cambia el estado del producto a "Devuelto" si la devolución es completa.
  5. Verificar el inventario: compruebe que la cantidad en el estante se haya actualizado correctamente después de la devolución.

Productos Retornables vs. Consumibles

El manejo de la devolución depende de si el producto fue marcado como retornable al momento de la reservación:

Tipo Retornable Ejemplo Devolución
Equipos Sí Microscopio, balanza, agitador Debe devolverse. El inventario se incrementa al devolver.
Materiales reutilizables Sí Cristalería, pipetas, probetas Debe devolverse. El inventario se incrementa al devolver.
Reactivos consumibles No Ácidos, solventes, indicadores No se espera devolución. La cantidad se descontó permanentemente.
Materiales desechables No Guantes, papel filtro, puntas No se espera devolución. La cantidad se descontó permanentemente.
Productos no retornables Para productos marcados como no retornables, el sistema no presenta la opción de devolución. La cantidad descontada del inventario no se recupera. Al cerrar la reservación, estos productos se consideran finalizados automáticamente sin necesidad de registrar una devolución.

Cierre de una Reservación

Una reservación puede cerrarse cuando se cumple alguna de las siguientes condiciones:

  • Todos los productos retornables han sido devueltos en su totalidad
  • Los productos no retornables ya fueron descontados del inventario
  • El encargado decide cerrar la reservación manualmente

Al cerrar una reservación, su estado cambia a "Cerrada" (valor 3). Una vez cerrada, no se pueden realizar más operaciones sobre ella. Los registros de la reservación y sus productos quedan disponibles para consulta y auditoría.

Desactivación de Usuarios en Reservaciones

En situaciones donde un usuario ya no forma parte de la organización o pierde acceso al laboratorio, el sistema permite gestionar sus reservaciones activas:

  • Las reservaciones pendientes del usuario pueden ser rechazadas por el encargado
  • Los productos prestados al usuario deben ser devueltos o registrados como pérdida antes de desactivar su acceso
  • El historial de reservaciones del usuario se mantiene para fines de auditoría
Importante sobre la desactivación Antes de desactivar a un usuario del sistema, asegúrese de resolver todas sus reservaciones activas. Los productos prestados que no sean devueltos pueden generar inconsistencias en el inventario. Revise las reservaciones en estado "Aceptada" del usuario antes de proceder con la desactivación.

Precisión del Inventario

Mantenga el inventario preciso El sistema de reservaciones está diseñado para mantener el inventario actualizado automáticamente. Sin embargo, es recomendable realizar verificaciones periódicas comparando las cantidades registradas en el sistema con las cantidades físicas en el laboratorio. Esto permite detectar discrepancias causadas por devoluciones no registradas, pérdidas o errores de manipulación.

Para mantener la precisión del inventario en relación con las reservaciones:

  • Registre las devoluciones tan pronto como ocurran
  • Verifique las cantidades devueltas contra las cantidades prestadas
  • Cierre las reservaciones completadas para evitar confusiones
  • Revise periódicamente las reservaciones en estado "Aceptada" con fechas vencidas
