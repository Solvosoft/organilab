Capítulo 5: Reservaciones

El sistema de reservaciones de Organilab permite a los usuarios solicitar el préstamo de equipos, sustancias y materiales del laboratorio. En este capítulo aprenderá cómo funciona el ciclo completo de una reservación, desde la solicitud hasta la devolución de los productos.

Gestión eficiente de recursos Las reservaciones permiten planificar el uso de los recursos del laboratorio de forma ordenada. El sistema controla la disponibilidad automáticamente, evita conflictos de fechas y ajusta el inventario cuando se prestan o devuelven productos. Esto garantiza que cada usuario tenga acceso a lo que necesita sin afectar el trabajo de los demás.

Contenido del Capítulo

1. Conceptos de Reservaciones

Estados de una reservación y de los productos reservados, ciclo de vida completo y terminología clave del sistema.

2. Solicitar Reservación

Cómo crear una solicitud de reservación, seleccionar productos del inventario, definir cantidades y fechas, y usar reservaciones masivas.

3. Gestionar Reservaciones

Aprobación y rechazo de solicitudes, validación de disponibilidad, gestión automatizada del inventario mediante tareas programadas.

4. Devolución de Productos

Proceso de devolución parcial o completa, cierre de reservaciones y manejo de productos no retornables.
