2. Código QR: Generación y Uso

El código QR es el elemento central del módulo de Registro de Usuarios. Cada usuario registrado en el sistema recibe un código QR único que lo identifica dentro de la organización o laboratorio y permite validar su identidad y permisos.

Código / Identificador único

Antes de generar el QR, cada usuario debe tener asignado un código único de identificación. Este código puede corresponder a:

  • Código interno — Asignado por el sistema administrativo de la institución
  • Número de identificación institucional — Carné, número de empleado o matrícula
  • Código de acceso — Generado específicamente para el control de acceso al laboratorio
Importancia del código El código único garantiza que no haya duplicados dentro del mismo laboratorio u organización. Este código queda incrustado en el QR generado y permite una identificación rápida y segura.

Generación del código QR

Una vez ingresada toda la información del usuario (incluyendo el código de identificación), el sistema permite generar un código QR asociado al usuario.

  1. Completar todos los campos del formulario — Nombre, correo, rol, organización y código.
  2. Seleccionar la opción "Generar código QR" — Aparece dentro del formulario de registro.
  3. El sistema genera el QR automáticamente — El código queda vinculado permanentemente al usuario.
  4. Guardar el registro — El QR se almacena y queda disponible para su uso e impresión.

Usos del código QR

El QR generado puede ser utilizado por el usuario para distintos propósitos dentro del sistema:

Ingreso al laboratorio

El QR sirve como credencial de acceso físico. Al escanearlo en la entrada, el sistema registra el ingreso del usuario con fecha y hora.

Identificación rápida

Permite identificar al usuario en cualquier momento sin necesidad de recordar credenciales. Útil para verificaciones rápidas.

Validación de identidad

Verifica que el usuario corresponde a la persona registrada en el sistema, confirmando su identidad ante el personal del laboratorio.

Consulta de permisos

Al escanear el QR, el sistema muestra los módulos y acciones autorizados para ese usuario según su rol asignado.

Control de acceso

Permite restringir el acceso a áreas específicas del laboratorio únicamente a los usuarios con los permisos correspondientes.

Aplicación práctica del QR

El código QR generado por Organilab puede imprimirse en:

  • Tarjetas de identificación personal (carné del laboratorio)
  • Listas de asistencia con verificación digital
  • Registros de ingreso y egreso del laboratorio
  • Documentos que requieren firma o validación de identidad
Buena práctica Se recomienda que cada usuario imprima su QR y lo mantenga consigo durante su permanencia en el laboratorio. El QR debe escanearse tanto al ingresar como al salir para un control preciso de presencia.
