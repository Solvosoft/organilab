1. Visualización y Registro de Usuarios

El módulo de Registro de Usuarios permite visualizar todos los usuarios asociados al laboratorio y registrar nuevos usuarios con su código de identificación y QR único.

Acceso al módulo

Para ingresar al módulo de Registro de Usuarios:

  1. Seleccionar la organización activa — Asegúrese de tener seleccionada la organización correcta.
  2. Ingresar a Mis Laboratorios — Acceda desde el menú principal.
  3. Seleccionar el laboratorio correspondiente — Elija el laboratorio en el que trabaja.
  4. En la Vista de laboratorio, elegir la subárea "Registro de usuarios" — Esta opción aparece en el menú lateral del laboratorio.
Nota Este módulo es diferente al módulo de "Organizaciones y Permisos". El Registro de Usuarios gestiona la presencia física de las personas en el laboratorio mediante un código QR, mientras que el módulo de permisos gestiona los accesos al sistema.

Visualización de usuarios registrados

Al ingresar al módulo, el sistema muestra la lista de usuarios registrados dentro del laboratorio u organización seleccionada.

La lista puede mostrar la siguiente información por usuario:

Campo Descripción
Nombre del usuario Nombre completo de la persona registrada
Correo electrónico Dirección de correo asociada al usuario
Rol asignado Rol del usuario dentro del sistema (Administrador, Técnico, etc.)
Estado Activo o Inactivo — determina si puede acceder al sistema
Código de identificación Código único institucional del usuario
QR generado Indicador de si ya se ha generado el código QR para el usuario
Organización asociada Organización o laboratorio al que pertenece

Registrar un nuevo usuario

Para registrar un nuevo usuario en el laboratorio:

  1. Seleccionar la opción "Crear / Registrar usuario" — Aparece como botón en la parte superior del listado.
  2. Completar la información solicitada — Llenar todos los campos requeridos del formulario.
  3. Generar el código QR — Una vez completados los datos, el sistema permite generar el QR único.
  4. Guardar el registro — Confirmar y guardar para que el usuario quede registrado.

Datos requeridos en el formulario

Campo Descripción Ejemplo
Estado Indica si el usuario estará Activo o Inactivo desde el inicio Activo
Tipo de rol Rol asignado dentro del sistema. Define los permisos disponibles. Técnico, Regente, Consulta
Organización Organización o laboratorio al que pertenece el usuario UNA / Laboratorio de Química
Código / Identificador Código único para identificar al usuario (código interno, número institucional o de acceso) 2024-001, 115230789

Estado del usuario

Al crear un usuario, se debe indicar si estará Activo o Inactivo. Este campo determina si la persona podrá utilizar el sistema y sus accesos asociados.

Activo

El usuario tiene acceso al sistema y puede utilizar sus permisos asignados. Su código QR es válido para controles de acceso.

Inactivo

El usuario no puede acceder al sistema. Se recomienda desactivar en lugar de eliminar para preservar el historial y trazabilidad.

Roles disponibles

Al registrar un usuario se debe asignar un rol. Algunos roles comunes en el sistema:

Rol Descripción general
Administrador Acceso completo al laboratorio y sus configuraciones
Regente Responsable técnico del laboratorio, puede generar reportes regenciales
Técnico Gestiona inventario y operaciones del día a día
Usuario de laboratorio Acceso básico para uso del laboratorio
Consulta Solo puede visualizar información, sin realizar cambios
Importante La asignación del rol define los permisos disponibles para el usuario. Asegúrese de asignar el rol correcto según las responsabilidades de cada persona dentro del laboratorio.
