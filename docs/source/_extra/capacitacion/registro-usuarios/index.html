Capítulo 7: Registro de Usuarios con QR

El módulo Registro de Usuarios permite incorporar nuevos usuarios al sistema y asociarlos a una organización o laboratorio mediante la generación y administración de un código QR único, así como la asignación de roles y estados de acceso.

¿Cuándo usar este módulo? Este módulo se utiliza para registrar formalmente a personas (estudiantes, técnicos, investigadores) que necesitan acceso físico al laboratorio. El QR generado les permite identificarse en el sistema y validar su identidad en controles de acceso.

Contenido del Capítulo

1. Visualización y Registro de Usuarios

Cómo acceder al módulo, visualizar la lista de usuarios registrados y crear un nuevo registro con todos sus datos requeridos.

2. Código QR: Generación y Uso

Proceso de generación del código QR único por usuario y sus aplicaciones: identificación rápida, control de acceso y validación de identidad en el laboratorio.

3. Gestión de Usuarios Registrados

Modificación de datos, cambio de estado (activo/inactivo), cambio de rol y desactivación de usuarios cuando ya no requieren acceso.
